ZWBIM 夹点定义 · GT-01~18 全量交互演示 v3.0

基于《ZWBIM夹点分析_最终方案汇总V6》Sheet4「夹点定义」18 个类型逐一配置，沿用既有视觉编码规范：蓝=几何编辑、橙=操纵/参数、灰=关系/曲线/批量，形状区分具体类型；5 种显示状态（普通/悬停/激活/锁定/禁用）。左侧选择类型，右侧画布直接拖拽/点击体验。

视觉样式规范映射（既有 11 类典型位置 → 18 个 GT）状态规则统一：普通=原色；悬停=高亮放大；激活=实心加大；锁定=灰色；禁用=隐藏（跨文件链接对象=锁定态）
典型出现位置（视觉样式规范源表）对应 GT夹点名称
夹点类型速查（点击可跳转场景）颜色=类别，形状=具体类型
配色逻辑：颜色 = 夹点逻辑类别与 V6 方案表 GT 归类一致
蓝 · 几何编辑类
GT-01 端点 / GT-02 中点 / GT-03 圆心 / GT-04 象限 / GT-06 顶点控制 / GT-07 轮廓范围 / GT-09 截面 / GT-14 标注定义点——直接改对象自身的几何（位置·尺寸·形状）。
橙 · 操纵 / 参数类
GT-05 插入点 / GT-11 参数 / GT-12 方向翻转 / GT-13 文字位置 / GT-15 临时尺寸——改实例属性、朝向或定位基准（操纵柄），不改几何形状。
灰 · 关系 / 曲线 / 批量 / 范围类
GT-08 路径 / GT-10 连接点 / GT-16 裁剪剖切 / GT-17 阵列间距 / GT-18 子对象无夹点——改连接关系、曲线形态、显示范围与批量副本。
中望品牌色：主色蓝 #2563EB、强调橙 #F5801F、中性灰 #6B7280。颜色只表「类别」，具体类型靠形状区分；悬停时空心夹点由空心变实心并放大（Revit 式高亮）。锁定态=跨文件链接对象（灰、不可编辑）；禁用态=无编辑权限（隐藏/虚化）。
5 种显示状态鼠标移上去看「悬停 / 激活」效果；「锁定」「禁用」为静态示例
